# MY音乐 PWA（iPhone 可用）

给只有 iPhone、没有 Mac 的情况准备的版本：一个网页 App，用 Safari 打开后「添加到主屏幕」，就能像 App 一样全屏使用。

**不影响原来的安卓工程**：这是一个独立目录，`app/` 下的 Kotlin 代码一行没改。

## 能做什么

- 搜索歌曲、在线播放、后台播放、锁屏控制（显示歌名和上/下一首）
- 收藏、搜索历史（存在手机本地）
- 歌单导入：粘贴文本 / 网易云 / QQ 音乐
- 歌词（接口返回）

## 做不到

- 读取手机本地音乐文件（Safari 限制）
- 从 App Store 下载（它是网页，不是原生 App）

## 部署（两步）

### 第一步：部署接口服务（必须，无内置音源/API）

浏览器直接请求曲库/网易云会被跨域策略拦下，所以需要一个免费代理。

1. 打开 <https://dash.cloudflare.com/> 注册（免费）。
2. 左侧 **Workers & Pages → 创建 → Worker**，名字随意，创建后点 **编辑代码**。
3. 把本目录的 `worker.js` 全部内容粘贴进去，覆盖默认代码，点 **部署**。
4. 记下分配的地址，形如 `https://xxx.workers.dev`，即为后续要填写的「接口地址」。

### 第二步：托管网页

把这个 `pwa/` 目录上传到任意静态托管，任选其一：

| 方式 | 说明 |
|---|---|
| Cloudflare Pages | 免费，拖拽上传，推荐 |
| GitHub Pages | 免费，需建仓库 |
| Vercel / Netlify | 免费，拖拽或连 Git |

只要保证 `index.html`、`app.js`、`style.css`、`manifest.json`、`sw.js`、三个 PNG 在同一目录即可。

> 本地预览：在 `pwa/` 目录执行 `python -m http.server 8080`，然后浏览器打开 `http://localhost:8080`。

## 在 iPhone 上安装

1. Safari 打开你部署好的网址（**必须用 Safari**，微信内置浏览器不支持安装）。
2. 点底部 **分享** → **添加到主屏幕** → 添加。
3. 从桌面图标打开，进入 **设置**，把第一步的 Worker 地址填进「接口地址」，保存。

## 使用说明

- **搜索**：输入歌名/歌手回车，依赖已部署的接口服务。
- **收藏**：点歌曲右侧 ♡。
- **导入**：
  - 「粘贴歌单导入」最稳：每行一首「歌名 - 歌手」，不需要登录。
  - 网易云/QQ：在电脑浏览器登录对应网页版，用开发者工具复制请求里的 Cookie，粘进来读取歌单。


## 常见问题

**添加到主屏幕后没图标？**
确认 `apple-touch-icon.png` 和网页在同一目录。

**点播放没声音？**
iPhone 要求先有用户操作才能播放。点一下歌曲即可；如果还是不行，检查接口服务是否部署正确。

**提示「未填写接口地址」？**
先去设置填写你部署的服务地址。

**网易云读不到歌单？**
Cookie 过期了，重新从网页版复制一次（要包含 `MUSIC_U`）。
